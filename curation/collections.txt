# ── Format ────────────────────────────────────────────────────────────────
#   [slug]                     start a collection (familles · grossesse · couples · portraits · mariages)
#   title:  Mariages           display title (FR)
#   title.en: Weddings         display title (EN)
#   intro:  ...                one line under the title (FR)
#   intro.en: ...              (EN)
#   cover:  IMG_8402 | FR alt text | EN alt text
#   IMG_3259 | FR alt text | EN alt text        ← one line per photograph, in hang order
#
#   Alt text is required (accessibility + SEO). Describe what is in the frame, in plain
#   language. Never name a client. The EN part is optional — it falls back to FR.

# ── Workflow ──────────────────────────────────────────────────────────────
#   1. npm run photos:sheets   → contact sheets of the whole raw library, to review
#   2. edit this file          → choose, order, describe
#   3. npm run photos:build    → optimises the chosen frames and publishes the galleries
